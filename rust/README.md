# Bundled Rust boundary

Python remains the control plane. Platform wheels bundle the `housekeeper-core` subprocess, which implements protocol version 1 capability discovery plus stable BLAKE3/SHA-256/SHA-512 full, sampled quick, and one-read identity hashing. Digests are byte-identical to the Python reference implementation. Build locally with `cargo build --manifest-path rust/Cargo.toml`; override discovery with `HOUSEKEEPER_CORE=/path/to/housekeeper-core`. Python falls back to its own backend if the binary is absent, incompatible, or fails. Movement, traversal, and manifest execution deliberately remain in the audited Python control plane.
